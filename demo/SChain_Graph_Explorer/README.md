# SChain Graph Explorer

Requires Python 3.10 or newer.

Run from the repository checkout: the renderer and styles are shared with `visualization/`.

```bash
python server.py --port 8080 --no-browser
```

Open **http://127.0.0.1:8080**. Windows users can also run `start_server.bat`; Linux/macOS users can run `./start_server.sh`.

Load a graph JSON from the Dataset menu. Evidence retrieval requires an internet connection.

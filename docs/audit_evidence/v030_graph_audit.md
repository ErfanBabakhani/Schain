## Architecture summary
Extraction becomes a resolved flat evidence-per-quote Parquet fact table. Accepted facts rebuild an edge-support cache; expansion reads cache and facts to enqueue upstream names in SQLite. Neo4j uses canonical-ID MERGE and evidence-record JSON strings to preserve per-quote provenance. Export independently reconstructs semantic edges and shortest supply distances from Parquet, optional SQLite, and the config loaded at export time. Export already prevents phantom parent paths, contextual tiers and >max_tier displayed tiers.

## Additional findings

1. **High: runtime and export disagree on witness eligibility.** support.aggregate_edge_support lines201-248 combines evidence any(), ontology all(), direction all(), expansion any() across rows; it ignores evidence_quote_grounded entirely. One evidence row can provide relevance and another evidence validity, even if no row provides both. graph_export._build_nodes_and_edges727-732 correctly requires one witness with all flags and grounding not false. Reproduced with an offline in-memory DataFrame: runtime eligible=True, export eligible=False. A single ungrounded fact also produced runtime eligible=True. Fix via shared one-witness gate; explicit false/missing flags must not be truthy pandas values. One fully valid source remains sufficient.
2. **High: --no-neo4j duplicates completion counts.** pipeline.process_document240-244 only skips COMMITTED, but lines327-329 deliberately leave no-driver documents RESOLVED. A revisit returns a successful non-skipped RESOLVED result and loop counts it again. Graph export lines1108-1110 counts only COMMITTED so normal no-driver runs report zero processed. Fix completed-for-current-mode semantics and count RESOLVED+COMMITTED for extraction completion, separate Neo4j committed metric.
3. **High: cross-origin dedup loses reusable upstream evidence.** state.register_document184-191 returns early without recording another origin. process_document duplicate/committed fast return227-244 skips origin association; _facts_for_entity uses only first registered origin. Same evidence containing edges into BMW and Toyota may be extracted once for BMW and never safely reused/promoted for Toyota. Need a non-LLM origin association mechanism referencing already validated facts, not duplicate extraction or unconditional relevance rewriting.
4. **Medium: full_text_support_count counts quotes as documents.** support.aggregate_edge_support198-200 and graph_export766-768 sum evidence rows; one document with two distinct quotes reports document_count=1/full_text_support_count=2 (offline reproduced). Count unique doc IDs and optionally expose evidence-item count separately. Score means also quote-weighted, making repeated quotes distort reputation metadata; mean by unique document is more informative.
5. **Medium: provider stats hide failures / zero-yield selected docs.** graph_export.build_graph_bundle1077-1081 builds documents only from accepted-fact references; statistics documents_by_provider/full_text documents therefore exclude selected no-fact documents and unselected retrieval candidates. source_providers counts quote evidence items. Add explicitly scoped run retrieval/selected/processed/full-text/accepted-expansion counters, keep old fields for consumers.
6. **Medium: stale cache false can demote new valid facts.** graph_export739-740 allows support.frontier_eligible=False to override fresh same-witness flags even though comment states facts are source of truth. After interrupted support write, newly accepted source could be valid but export demotes it. Recompute eligibility and reason from facts; only explicit recorded conflict should override (subject to conflict source design).
7. **Medium: legacy verification pseudo-facts only filtered in support.** support._group_evidence50-52 ignores doc_id starting verify:, exporter._load_facts has no equivalent. Older artifacts may show these as global facts and inflate export fact/evidence counts. Ignore such pseudo-facts consistently; do not alter original Parquet.
8. **Low: alias/shortest-path and cycles mostly correct.** Export seed alias matching only merges unambiguous aliases (566-578); BFS makes shortest tiers and terminates on cycles, seed zero preserved; _apply_tier_semantics demotes orphan tiers shallowest-first. Do not reject genuine reciprocal supply automatically. Could expose cycle count diagnostically but no broad refactor justified.
9. **Low: no publisher in final document JSON.** Documents may preserve publisher_name/domain but _build_documents omits these. Export provenance should carry these informational fields; do not make publishers graph entities.
